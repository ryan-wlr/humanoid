# OpenUSD Kitchen Set (local asset)

This folder is used for downloading and unpacking the official OpenUSD **Kitchen Set** sample scene.

- Source: https://openusd.org/release/dl_kitchen_set.html
- Direct download: https://openusd.org/files/Kitchen_set.zip

Downloaded content is intentionally ignored by git.

## Marker file
After a successful download, the script writes:
- `kitchen_set_usd_path.txt` (absolute path to the main `Kitchen_set.usd`)
